## 1. The invention, in one paragraph

A display element (an orb) whose **colour palette, motion, and behaviour are
functionally driven by the internal emotional state of a personal AI**, where
that state derives from a **persistent, user-owned model of one person**
(learned priorities, corrections, detected risks and opportunities) — not
from call mechanics, audio amplitude, or developer-set branding. The orb is
an instrument panel for a mind: *protective* because a risk to the user was
detected; *happy* because a correction was just learned; *charged* because an
interrupt-worthy opportunity was found. Distinct moods carry distinct colour
palettes with live transitions, and the mapping is generated by the engine
(`orb_state()` in `connector/conscience.py`), not authored per conversation.

## 3. Market landscape (captured 2026-08-14)

Recorded for contrast, from public documentation. No claim of wrongdoing is
made or implied.

- **ElevenLabs UI "Orb" component** (ui.elevenlabs.io/docs/components/orb;
  also github.com/elevenlabs/ui): 3D audio-reactive orb whose API accepts
  `agentState` — call mechanics only (`null`/idle, `listening`, `talking`,
  `thinking`) — and `colors`, a **static two-colour gradient chosen by the
  developer as branding** (doc examples: `["#CADCFC","#A0B9D1"]`). No
  emotion, mood, or sentiment input exists in the component API; colours do
  not change at runtime with any state.
- ElevenLabs emotion features live elsewhere in their stack: expressive
  *voice* delivery, and *sentiment analysis* as post-conversation business
  analytics. Neither drives the orb display.
- **Apple Siri (2011→)**: audio-reactive colour-shifting sphere; no
  emotional model; call-state indicator.
- General pattern: market orbs are **presence/call-state indicators with
  developer-fixed palettes**. As of the capture date we find no shipped
  product in which orb colouration is functionally driven by an AI's
  persistent, learned emotional state about an individual user.

## 4. The distinguishing elements (claim-mapping shorthand)

| Element | Market orbs (above) | JEFFEREY orb |
|---|---|---|
| What the display shows | Call state (listening/talking) | Emotional state of the AI about *this user* |
| What drives colour | Developer-set static gradient | Live mood → palette mapping (8+ moods), engine-generated |
| Source of state | Microphone/session activity | Persistent owned conscience: learned priorities, corrections, detected risks/opportunities |
| Persistence | None (per call) | Survives sessions and engines; state carried in user-owned store |
| Behavioural layer | Audio-reactive motion | Touch reactions, temper escalation, spontaneity, memory of visitor |
